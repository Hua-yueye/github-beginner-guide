## 常用词汇

| 英文 | 中文含义 |
| --- | --- |
| Repository | 仓库，保存项目文件和修改历史 |
| README | 项目的首页说明文件 |
| Commit | 提交，保存一次修改记录 |
| Branch | 分支，用于分别开展不同的修改 |
| Issue | 议题，用来记录问题、需求和任务 |
